# 运行资料清单

`content/` 只保存正式运行功能使用的人格、知识资料及其人工导入模板。
这些文件即使使用 Markdown，也属于程序输入，移动或删除前应检查下面的读取方。
开发测试素材、示例研究文字和一次性验收清单不放在这里；测试通过代码构造临时资料。
供人阅读的功能说明和活跃开发计划见 [docs](../docs/README.md)。一次性测试与验收结果记录在提交或 PR 中。
本清单本身不导入模型。

## 使用可选人格

1. 打开 AstrBot 后台的人格管理，新建独立人格，名称建议为“大肥鱼·自由人格”。
2. 将[大肥鱼自由人格](persona/大肥鱼-自由人格.md)中分隔线 `---` 后的全部正文复制到系统提示词并保存；工具与技能按现有配置选择。
3. 在需要使用它的配置文件中选择该人格；已有会话若单独绑定了其他人格，也需改为新的人格。原“大肥鱼”人格保留，方便切回。

首次安装仍默认使用“大肥鱼”；后续保存配置向导设置会保留后台已经选中的人格。

模板中的浏览、分享和记忆记录依赖运行态已有的工具与权限；导入人格本身不会启用这些能力或创建 `memory/说话方式.md`。

## 维护方式

- **先查读取方再删除或改名**，同步修改脚本路径、引用和相关回归；不要只按扩展名判断能否删除。
- 同时供人阅读和程序使用的资料，只在这里维护正文，`docs/` 通过链接导航，不再复制一份。
- 知识库名称仍为“大肥鱼手册”和“热梗词典”。已导入的数据保存在独立运行目录，源文件改名不会自动改写既有知识库。
- 初始化脚本在知识库非空时跳过上传；修改资料后需明确更新知识库，不能把源码文件已更新当作机器人已用上新版。
- 人格、知识库和人工导入模板按已有入口使用；本清单不会启动导入、模型调用或定时任务。
- 账号、API Key、聊天记录、实际投递回执和私人记忆继续保存在独立运行目录，不放入本目录。
