# 运行资料清单

`content/` 保存供程序读取、导入或显式提交给模型的源资料，以及注明用途的可选模板。
这些文件即使使用 Markdown，也属于程序输入，移动或删除前应检查下面的读取方。
供人阅读的功能说明、开发计划和验收报告放在 [docs](../docs/README.md)。本清单本身不导入模型。

| 资料                                     | 读取方与触发时机                                             | 影响                                                                   |
|------------------------------------------|--------------------------------------------------------------|------------------------------------------------------------------------|
| [大肥鱼人格](persona/大肥鱼-人格.md)     | `tools/initialize_api.py` 在目标人格尚未存在时读取并创建人格 | 缺失会影响首次人格初始化；修改源文件不会覆盖已存在的人格               |
| [指令手册](knowledge/指令手册.md)        | `tools/initialize_api.py` 在“大肥鱼手册”知识库为空时导入     | 是机器人可检索的知识来源，也供人查阅指令；不要当成可随意清理的说明副本 |
| [热梗词典](knowledge/热梗词典.md)        | `tools/initialize_api.py` 在“热梗词典”知识库为空时导入       | 是实际知识库来源，原文件名中的“示例”已去掉                             |
| [自主生活验收资料](自主生活验收资料.md)  | 显式执行 `python tools/life_trial.py prepare` 时提交         | 是验收工具的研究素材，不是已发生的经历或验收通过记录                   |
| [课程记忆模板](persona/课程记忆-模板.md) | 可选的人工导入模板，当前没有程序自动读取入口                 | 保留供维护者参考；放在目录中不代表已经写入记忆                         |

## 维护方式

- **先查读取方再删除或改名**，同步修改脚本路径、引用和相关回归；不要只按扩展名判断能否删除。
- 同时供人阅读和程序使用的资料，只在这里维护正文，`docs/` 通过链接导航，不再复制一份。
- 知识库名称仍为“大肥鱼手册”和“热梗词典”。已导入的数据保存在独立运行目录，源文件改名不会自动改写既有知识库。
- 初始化脚本在知识库非空时跳过上传；修改资料后需明确更新知识库，不能把源码文件已更新当作机器人已用上新版。
- 人格、知识库和验收素材按已有入口使用；本清单不会启动导入、模型调用或定时任务。
- 账号、API Key、聊天记录、实际投递回执和私人记忆继续保存在独立运行目录，不放入本目录。
