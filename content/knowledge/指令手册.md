# Windows 分享版补充

当前启用的语音节点配置 API Key 后，尚未设置开关的会话默认允许语音；未配置时默认关闭。
/语音开 仅允许当前会话按上下文自动语音，并非每条都朗读；/语音关
关闭普通聊天语音。主动消息语音独立允许，也默认文字。明确请求跳舞、转圈、摆姿势，在没有视频节点时会实际生成一张动作自拍，默认补简短文字，明确要配语音时才出声。语音拟声不是歌曲生成。

自拍会按描述选用吃饭、困惑、惊讶、招手微笑、睡觉、动态姿势或日常坐姿的角色参考图，其他场景或缺少对应图片时使用基础图。
可以发 `/自拍 朝镜头招手` 或直接说“给我看看你吃饭的样子”。用户附图也会参与生图。
直接说“生成一张自拍图片”即可：未指定场景时，她会结合最近自己说的状态和北京时间自行选景。
例如她刚说在睡觉，再接“真的吗？给我看看”，会生成睡觉场景的自拍并自然接话，
不要求你改用指令。仅询问“你在做什么”、讨论自拍用法、要看代码或题目时不会自动生成自拍。

以下保留上游手册，Windows 安装与当前功能以[项目说明](../../README.md)为准。

# 🕹️ 指令手册（速查表）

> 使用方式： **私聊直接发**； **群聊**里 @ 她 或直接以 `/` 开头（`/` 本身就是唤醒词）。
> 标 👑 的指令仅管理员（主人）可用。
> 大部分需求也可以 **直接用自然语言说**（"给我画个…""来个自拍""点首歌"），她会自己调用对应能力。

## 🔊 语音开关（本项目插件提供）

| 指令        | 作用                                       |
|-------------|--------------------------------------------|
| `/语音开`   | 允许当前会话按上下文自动选择语音           |
| `/语音关`   | 关闭当前会话的普通聊天语音（主动消息独立） |
| `/语音状态` | 查询当前开关状态                           |

> 会话级生效，显式开关重启保留，并优先于根据 API Key 计算的默认状态；没有显式设置时不固定保存默认值，后续增删
> Key 会自动跟随。免 Key 的语音节点可用 `/语音开` 手动允许。
> 开启表示允许必要的语音，平时优先文字；明确要听、安慰鼓励或确实重要的事才考虑简短语音，不按概率朗读。
>
一轮通常只选一种表达。确需同时发送时，语音表达情绪或强调，文字另给链接、名称、时间地点、步骤等可保存的信息，不换说法重复。近期刚发过语音会优先回文字，明确要求或紧急重要情况可例外。主动消息独立允许语音，同样不强制出声。

## 🎵 点歌（music 插件）

也可以直接说「点首歌」「放一首歌」「播放《成都》」或「我想听周杰伦的晴天」。
没有提供歌名时会先询问，接着回复歌名即可；点歌发送歌曲与普通聊天语音开关独立。

Windows 版选歌后会提示准备状态。歌曲下载后通过本机文件路径交给 NapCat 发送，
避免整首歌转换为 WAV/base64 后超过传输上限；每种歌曲发送方式最多等待 30 秒，
超时后按配置回退播放链接。下载与音源解析另有限时，不影响普通聊天语音设置。
歌曲缓存按平台和歌曲 ID 复用，保留 7 天，新缓存总容量最多 512 MiB。

| 指令         | 作用                                                                           |
|--------------|--------------------------------------------------------------------------------|
| `/点歌 歌名` | 发歌 / 卡片 / 语音条（别名：网易点歌、QQ点歌、酷狗点歌、酷我点歌、全民K歌 等） |
| `/查歌词`    | 查看歌词（别名：查看歌词）                                                     |

## ⏰ 定时服务（AstrBot「未来任务」）

- 定时任务通过配置向导按需启用；实际任务及时间以后台列表为准。
- 管理入口：面板 → 未来任务（可暂停 / 改时间 / 加新时段）
