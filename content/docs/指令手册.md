# Windows 分享版补充

/语音开 仅允许当前会话按上下文自动语音，并非每条都朗读；/语音关
关闭普通聊天语音。主动消息语音独立。明确请求跳舞、转圈、摆姿势，在没有视频节点时会实际生成一张动作自拍并配简短语音，语音关闭则补文字。语音拟声不是歌曲生成。

以下保留上游手册，Windows 安装与当前功能以仓库 README 为准。

# 🕹️ 指令手册（速查表）

> 使用方式： **私聊直接发**； **群聊**里 @ 她 或直接以 `/` 开头（`/` 本身就是唤醒词）。
> 标 👑 的指令仅管理员（主人）可用。
> 大部分需求也可以 **直接用自然语言说**（"给我画个…""来个自拍""点首歌"），她会自己调用对应能力。

## 🔊 语音开关（本项目插件提供）

| 指令        | 作用                                       |
|-------------|--------------------------------------------|
| `/语音开`   | 允许当前会话按上下文自动选择语音           |
| `/语音关`   | 关闭当前会话的普通聊天语音（主动消息独立） |
| `/语音状态` | 查询当前开关状态                           |

> 会话级生效、重启保留；在哪个会话发的就管哪个会话。开启后由模型按上下文决定文字、语音或互补表达，不按概率随机朗读。主动消息保留独立自动语音。

## 🎨 画图 · 自拍 · 视频（omnidraw 插件）

| 指令                                           | 作用                                                                                  | 示例                                 |
|------------------------------------------------|---------------------------------------------------------------------------------------|--------------------------------------|
| `/画 提示词`                                   | 文生图：任意画面                                                                      | `/画 星空下的码头`                   |
| `/自拍 场景描述`                               | 以官方立绘为参照，把"她"放进新场景                                                    | `/自拍 在窗边捧着奶茶发呆，午后阳光` |
| `/视频 提示词`                                 | 文生视频（需先配视频模型）                                                            |                                      |
| 👑 `/人设`、`/切换人设 [序号/名称]`            | 查看 / 切换生图人设                                                                   |                                      |
| 👑 `/切换模型 画图/自拍/视频 [序号或名称]`     | 查看或切换该链路使用的模型（序号从 0 开始）                                           | `/切换模型 自拍`                     |
| 👑 `/切换链路 目标 [节点ID]`                   | 切换链路走的节点（目标：画图／自拍／视频／副脑；节点如 node_1 免费档、node_2 保真档） | `/切换链路 自拍 node_2`              |
| `/查看预设 [名]`、👑`/添加预设`、👑`/删除预设` | 提示词预设管理                                                                        |                                      |
| `/签到`、`/清理缓存`、`/万象帮助`              | 每日签到 / 清理临时缓存 / 插件完整帮助                                                |                                      |

## 🎵 点歌（music 插件）

| 指令         | 作用                                                                           |
|--------------|--------------------------------------------------------------------------------|
| `/点歌 歌名` | 发歌 / 卡片 / 语音条（别名：网易点歌、QQ点歌、酷狗点歌、酷我点歌、全民K歌 等） |
| `/查歌词`    | 查看歌词（别名：查看歌词）                                                     |

## 😀 表情相关

| 指令 / 行为                                          | 说明                                                                             |
|------------------------------------------------------|----------------------------------------------------------------------------------|
| 平时的她                                             | 自动使用真 QQ 表情（`[旺柴]`→真表情段由本项目插件完成）                          |
| `/贴表情`                                            | 让她贴一张 QQ 表情（群聊场景她会自动贴，私聊可用此指令）                         |
| `/meme列表`                                          | 查看表情包模板（别名：表情帮助 / meme菜单 / meme帮助）                           |
| （前缀或 @她）+ 模板名                               | 触发表情包制作，如 `/摸头 @某人`                                                 |
| `/meme详情`、`/禁用meme`、`/启用meme`、`/meme黑名单` | 模板详情与管理                                                                   |
| （自动）聊天中                                       | 表情包"偷取"：你们聊到的表情包她会自己收集分类（stealer 插件，管理面板在 WebUI） |

## 👆 互动

| 指令 / 行为      | 说明                                     |
|------------------|------------------------------------------|
| 直接**戳一戳**她 | 有反应（炸毛 / 回话 / 反戳，取决于配置） |
| `/戳`            | 主动发一个戳（别名：戳我 / 戳全体成员）  |

## ⏰ 定时服务（AstrBot「未来任务」）

- 已配示例：每晚 **23:30 催睡觉**、每天 **07:00 叫起床**（任务配方见 README《推荐搭配》）
- 管理入口：面板 → 未来任务（可暂停 / 改时间 / 加新时段）

| 指令        | 作用                                                   |
|-------------|--------------------------------------------------------|
| `/help`     | 指令帮助                                               |
| `/reset`    | 重置当前会话上下文                                     |
