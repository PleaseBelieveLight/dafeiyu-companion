使用本次自拍的动作/场景描述匹配；自然语言请求由聊天模型将上下文写入工具的
`action`。明确 Q 版要求优先；户外场景不会仅因“晚上”切换为卧室参考。
服装、动作、背景与构图服从本次要求。每次仅选择一张角色参考，用户附图仍参与请求。
缺图时回退日常图，再回退原配置参考图；其它人设维持其各自配置。
