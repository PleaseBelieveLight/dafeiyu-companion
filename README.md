# 🐳 大肥鱼 QQ 机器人

**在自己的 Windows 电脑上，养一只会在 QQ 里陪你聊天的大肥鱼。**

你可以像给好友发消息一样和大肥鱼聊天，也可以把她加进指定的 QQ 群。安装和配置都能在 Windows 里双击完成，无需编程。

[能做什么](#能做什么) · [下载与安装](#下载与安装) · [常见问题](#常见问题) · [帮助与反馈](#帮助与反馈) · [版权与致谢](#版权与致谢)

## 能做什么

- **在 QQ 里互动。** 私聊、在群里 @ 她、发个表情或戳一戳，也可以说「点首歌」。
- **看图、听语音、发自拍。** 可以发张照片问「这是什么」，或请她「发一张在窗边喝奶茶的自拍」。看图、视频理解、语音和生图按需配置。
- **记住聊过的事。** 开启长期记忆后，她可以在以后聊天时想起你提过的偏好或话题。你也可以调整她的性格和说话方式。
- **提醒和跟进。** 配置相应功能后，可以说「十分钟后提醒我休息一下」，也可以在私聊里约她「明天方便时问我面试结果」。

## 下载与安装

### 安装前准备

- **Windows 10 或 11（64 位）**，建议预留 **15–20 GB** 磁盘空间，首次安装需要联网。
- **Python 3.12（64 位）**。在官网的 Windows 下载项中选择 **Windows installer (64-bit)**，安装时保留默认的
  pip 和 Tcl/Tk
  组件。[Python 3.12 Windows 安装包](https://www.python.org/downloads/release/python-31210/#files)
- **两个 QQ 账号**。用你平时的账号与大肥鱼聊天，另准备一个账号给机器人登录。
- **DeepSeek API Key**。这是让机器人调用聊天模型的密钥，可在 DeepSeek
  控制台创建。调用费用以服务商为准。[DeepSeek 控制台](https://platform.deepseek.com/)

### 第一次启动

1. **下载并解压。** 在发布页展开 **Assets（附件）**，下载文件名以 `dafeiyu-companion-v` 开头、以 `.zip`
   结尾的压缩包。[前往下载](https://github.com/PleaseBelieveLight/dafeiyu-companion/releases)
   如果发布页没有提供附件，也可以在当前仓库页面点击 **Code → Download ZIP**，解压后按同样的步骤安装。
2. **安装组件。** 打开解压后的 `scripts → 安装配置` 文件夹，双击 `安装.cmd`，等安装完成。
3. **填写配置。** 回到解压后的主文件夹，双击 `配置向导.cmd`。填入你的 QQ 号、机器人 QQ 号和 DeepSeek API
   Key。如需让其他好友或群使用，也可在这里填写允许的号码。点击 **保存配置并启动**。
4. **登录机器人 QQ。** 在 `scripts → 安装配置` 里双击 `打开NapCat.cmd`，用手机 QQ 扫码登录机器人账号并完成验证。
5. **发第一条消息。** 用你平时的 QQ 私聊机器人，发一句「在吗？」。收到回复后，就可以开始聊天了。

安装组件和本机数据默认保存在项目文件夹内的 `.local`，包括账号配置、聊天记录和长期记忆。
更新项目时请保留这个文件夹；清理缓存时不要删除整个 `.local`。[目录与备份说明](scripts/README.md#本地运行与数据目录)

## 常见问题

### 电脑关机后，大肥鱼还能回复吗？

电脑需要保持开机、联网，且机器人服务正在运行。平时可以在项目主文件夹双击 `启动全部.cmd`、`停止全部.cmd`
或 `检查状态.cmd`。

### 大肥鱼在本机运行，为什么还要联网？

本机负责运行机器人和保存运行数据。发送和接收消息需要连接 QQ，聊天和看图等功能会把处理所需的内容发给你配置的在线模型服务。

### 发了消息却没回复怎么办？

先双击 `检查状态.cmd`，确认服务正在运行、机器人 QQ 已登录，再到配置向导检查 QQ
号、允许的好友或群，以及聊天模型密钥。[Windows 脚本使用说明](scripts/README.md)
