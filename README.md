# 大肥鱼 QQ 机器人 · Windows 本地项目

基于 [whyever77/dafeiyu-astrbot](https://github.com/whyever77/dafeiyu-astrbot) 整理的 Windows 本地部署项目，包含已验证的配置向导、语音回复、动作配图和网页配置修复。

仓库提供代码与安装器。Python 环境、AstrBot、NapCat、模型和运行数据在安装时生成，不放进 Git。**每位使用者自行填写 QQ、API Key 并扫码登录；不会继承原部署者的密钥、好友资料或聊天记录。**

## 工作目录与本地数据

三个目录职责固定：

| 目录 | 用途 |
| --- | --- |
| `D:\dafeiyu-companion` | 私有开发项目；修改、测试和 Git 提交均在这里进行 |
| `D:\Dafeiyu` | 本地运行与数据目录；存放依赖、模型、配置、登录状态、聊天记录和缓存 |
| `D:\dafeiyu-astrbot-main` | 外部最新上游源码，仅用于对照，不是运行依赖 |

所有日常 `.cmd` 入口都从 **`dafeiyu-companion`** 使用。管理脚本、人格文档和语音中转源码直接从本项目读取；`plugins/` 和 `overlays/` 的修改通过 **`部署更新.cmd`** 同步到运行目录，不重新下载依赖。运行目录原有按钮保留为跳转入口。

项目完全不读取 `Dafeiyu/source/dafeiyu-astrbot-main`。迁移旧安装可运行 `python tools/launch.py deploy --prune-legacy-source`：先备份代码和配置，再移开旧源码、验证并重启相关服务，成功后清理旧副本。QQ 登录进程保留，配置或验证失败会恢复原来的代码。

**`Dafeiyu` 不可整体当作临时缓存删除**：其中 `config/`、`astrbot/data/`、NapCat 登录资料和备份包含需要保留的本地数据。个人配置和运行数据不会进入私有项目的 Git。

默认运行目录是项目旁的 `Dafeiyu/`，不依赖启动时的当前目录。需要其他位置时，先设置 `$env:DAFEIYU_RUNTIME_ROOT = 'E:\Dafeiyu'`；安装器 `--root` 应使用相同位置。

## 功能

| 功能 | 配置要求 |
| --- | --- |
| QQ 私聊、群聊、30% 概率参与允许的群 | QQ 账号、聊天模型 Key、QQ 白名单 |
| 看图、看视频、听语音 | 百炼视觉/ASR Key、FFmpeg |
| 聊天语音、主动语音 | 百炼 TTS Key 与可用音色；也可使用 Edge TTS |
| 画图、人设自拍、跳舞等动作配图 | 可用生图接口、模型、账户额度 |
| 收集与发送表情、点歌、戳一戳 | 对应插件与联网服务 |
| 长期记忆、手册知识库 | 本地 Ollama + bge-m3 |
| 主动聊天、定时任务 | 填写主人 QQ；在向导中开启对应开关 |
| 只读网页浏览 | 本机 Chrome 或 Edge，独立浏览器资料目录 |
| 虚拟手机、逛 B 站、听模拟器声音 | 雷电等 Android 模拟器、ADB、专用设备序列号；应用需自行安装 |
| 视频生成 | 插件支持，但必须另配视频节点；默认不包含视频生成账户 |

普通聊天需先发送 `/语音开`，机器人再按上下文选择文字、语音或互补内容；`/语音关` 关闭当前会话普通语音。主动消息使用自己的语音设置。拟声语音不是歌曲生成。

运维 MCP 的日志、二维码、重启等工具默认仅管理员可调用；普通好友仍可使用聊天和已配置的媒体功能。

新安装的长期记忆和收集表情库从空白开始，需要自行聊天、收录素材；不会携带原部署者的历史数据。

明确的“给我跳个舞看看”“转一圈”“摆个姿势”等请求，在没有视频节点时会实际调用一次自拍工具，成功发图后配一句短语音；同一请求不会重复生图。失败会说明原因。

`/自拍` 发图成功后，会用已配置的看图模型识别一次成图，并接着当前聊天自然回复。聊天中调用自拍工具也会返回实际画面摘要；最近自拍记录按会话隔离、重启保留，不会把自己发的自拍当成用户照片。生成/发送失败不记录成功；识别失败只记录已发图，不编造画面。每次成功自拍额外调用一次看图接口；命令发图后另有一次普通聊天调用。系统最多保存最近 12 条摘要，每轮只带入当前对话最近 3 条，不保存成图链接或图片到源码。

## 安装

适用 **Windows 10/11 x64 + Python 3.12 x64**。Python 安装时勾选 pip 和 Tcl/Tk；可从 [Python 官方下载页](https://www.python.org/downloads/windows/) 获取。建议预留 15–20 GB 磁盘空间，首次安装需要联网。

1. 将仓库克隆或解压到本地目录，例如 `D:\dafeiyu-companion`。
2. 双击 **`安装.cmd`**。安装器校验并下载依赖，创建两个独立虚拟环境，准备 bge-m3。不会启动 QQ 或发送消息。
3. 双击 **`配置向导.cmd`**，填写下方必填项，点击“保存配置并启动”。
4. 双击 **`打开NapCat.cmd`**，用手机 QQ 扫描机器人账号的二维码并确认。QQ 风险验证必须在手机官方 QQ 中由账号本人完成。
5. 私聊机器人发送“在吗”；需要语音再发送 `/语音开`。

安装进度和依赖错误会显示在安装窗口。pip 下载失败时重跑安装即可，缓存会复用，已有配置不会被清空。安装器不会覆盖无关的非空目录。

### 必填配置

- **你的 QQ 号**：主人账号；与“机器人 QQ 号”分别填写。
- **机器人 QQ 号**：独立登录 NapCat 的账号。
- **DeepSeek API Key / 聊天模型**：默认模型名来自此部署的已验证配置，请确认自己的账户可调用。
- **百炼 API Key / 视觉模型 / 语音模型 / 音色**：启用对应功能时填写。自定义音色必须属于自己的账户；示例音色可按账户支持情况调整。
- **生图 API Key / 完整接口 URL / 模型**：默认是方舟 Seedream 图片接口；视频要在万象画卷里另配视频 Provider。账户额度不足的 HTTP 429 需要到服务商控制台处理。
- **其他允许的好友 QQ / 允许的群号**：多个号码使用英文逗号分隔。普通使用者无需获得管理员权限，也不需要单独配置 Key；请求共用部署者的服务账户。

项目中的 `config/settings.example.json` 是空密钥模板；实际 `Dafeiyu/config/settings.json` 和 `Dafeiyu/config/local-access.json` 保存在运行目录。面板账号、密码在配置向导“管理入口”查看。

### 启动和端口

日常使用 `启动全部.cmd`、`停止全部.cmd`、`检查状态.cmd`。先停止旧部署再启动新部署；安装器、启动器不会抢占其他部署的端口。

| 服务 | 默认地址 |
| --- | --- |
| AstrBot | http://127.0.0.1:6185 |
| NapCat | http://127.0.0.1:6099/webui/ |
| QQ 反向 WebSocket | 127.0.0.1:6199 |
| 独立 Ollama | 127.0.0.1:11435 |
| Phone / Browser / ASR | 127.0.0.1:8009 / 8010 / 8012 |

主动消息默认在允许的主人会话开启，间隔 2–4 小时，23:00–08:00 免打扰，连续两次未获回复后暂停。每次私聊新消息会重新计时。QQ 掉线时，主动消息同样无法送达。

### 虚拟手机与浏览器

浏览器优先自动识别本机 Chrome 或 Edge；未识别时，在向导填写浏览器可执行文件路径。

手机功能需要自己安装模拟器并创建专用实例，在配置中填写 `emulator_directory`、`emulator_index`、`emulator_serial`。默认索引 1 / `emulator-5556` 仅为示例；必须与实际专用实例一致。可在安装目录 `bin/platform-tools/adb.exe devices` 查看序列号。

运行 `..\Dafeiyu\runtime\astrbot\Scripts\python.exe tools/setup_phone.py` 可将下载并校验过的 ADBKeyboard 安装到配置中的专用设备。B 站等应用请在模拟器中从官方渠道安装。PhoneMCP 只允许操作这个序列号。系统声音转写使用 Windows 默认输出设备的 loopback，播放时需要音频设备可用。

## 源码与依赖

- `tools/`：安装、配置向导、服务管理、本地 MCP、ASR。
- `plugins/`：原项目的两个插件及本部署修改。
- `overlays/`：AstrBot、主动聊天和 PhoneMCP 的兼容补丁。
- `content/`：公开人格和知识库文档。
- `dependencies.lock.json`：上游提交、下载地址和完整性校验。
- `requirements/*.lock.txt`：分开的 Python 依赖快照，避免 AstrBot 与 Phone/Browser MCP 的 MCP 大版本冲突。
- `tests/`：安装与隐私检查；安装后还有实际插件、回复发送和网页初始化回归测试。

源代码依赖锁定 Git 提交，并校验去除 ZIP 根目录后的完整文件树。NapCat、面板、ADB、Ollama 校验 SHA-256。FFmpeg 固定 8.1 构建系列，下载时读取发布者的 SHA-256 校验；已有已验证缓存可以复用。下载缓存不包含在 Git 中。

在 GitHub 新建空仓库后，在本目录执行（仓库地址替换成自己的）：
